# 领域文档规则

本仓库采用单上下文（single-context）布局：

- 根目录 `GLOSSARY.md`：领域术语。
- `docs/adr/`：架构决策记录。

## 阅读时机

探索代码前，读取已有的 `GLOSSARY.md`，并阅读与当前工作相关的 ADR。文件尚不存在时直接继续；术语确定或需要记录决策时，由 `domain-modeling` 按需创建。

## 术语与决策

规格、假设、测试名称和重构建议使用词汇表中的名称。新概念先核对现有术语；确认是词汇表缺项时，交给 `domain-modeling` 补充。

方案与已有 ADR 冲突时，指出 ADR 编号、冲突内容和重新讨论的理由，再决定是否修订该决策。
