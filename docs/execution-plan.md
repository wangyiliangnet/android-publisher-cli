# 维护路线图

本页记录新版仍需验证和实现的工作。当前命令见 [README](../README.md)。修改规则见[贡献指南](../CONTRIBUTING.md)。

| 工作 | 验收条件 |
| --- | --- |
| 逐一验证六个渠道的测试账号 | 保存不含凭据的字段和结果摘要，区分账号权限与公开上架 |
| 补充响应丢失核对依据 | 只在官方协议能绑定本次操作时解除未决写入 |
| 增加新版状态备份与恢复 | 恢复后先核对远端，阻止旧备份触发重复写入 |
| 验收 npm 包交付 | 从实际 tarball 安装，核对文件清单和版本 |

首次上架、定时发布、旧版 Go 状态迁移和 npm 注册表发布不在当前实现范围内。新增范围时，先写明操作者的步骤和验收条件。

0.1.x 公开测试版的历史检查见[归档记录](archive/public-beta-acceptance.md)。归档描述旧版 Go 实现，不能作为新版账号验证结果。
