# 维护路线图

本页记录待完成的工作，供维护者安排。当前功能见[README](../README.md)。变更检查要求见[贡献指南](../CONTRIBUTING.md)。早期测试和审查过程见[归档记录](archive/public-beta-acceptance.md)。

## 待推进事项

| 工作 | 从哪里开始 | 需要保留的限制 |
| --- | --- | --- |
| 验证各渠道账号权限和应用绑定 | 在操作者本机，先运行只读命令并使用测试应用 | 真实账号证据不进入公开仓库 |
| 补充只读恢复依据 | 先确认渠道协议支持哪些可验证结果 | 没有公开依据的响应丢失路径继续阻塞 |
| 跟进官方文档或响应结构变化 | 增加合成兼容用例，更新协议来源记录 | 测试通过与真实账号验证分开记录 |
| 配置团队签名和公证 | 独立配置 Developer ID 签名、Apple 公证，再到目标 Mac 验证 | 现有 CI 预览不提供这些凭据或信任身份 |
| 提高人工审查要求 | 第二名人工维护者加入后，调整必需 PR 批准数量 | 当前人员条件尚未满足 |

## 另行立项的范围

首次上架、定时发布、新的生产自动化或调度，以及 Apple Silicon Mac 之外的平台支持，均需另行立项。先明确需求和验收条件，再安排工作。

浏览器登录和人工状态录入，继续用于自动查询无法确认的具体问题。
