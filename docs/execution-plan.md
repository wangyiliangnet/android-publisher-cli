# 维护路线图

面向规划后续工作的维护者。当前功能入口见[README](../README.md)，变更验收要求统一维护在[贡献指南](../CONTRIBUTING.md)，早期测试和审查过程见[归档记录](archive/public-beta-acceptance.md)。

## 待推进事项

- 在操作者本机验证各渠道账号权限和应用绑定，从只读命令与测试应用开始。公开仓库不保存这些真实账号证据。
- 渠道协议支持时，补充可验证的只读恢复依据；未公开的响应丢失路径继续阻塞。
- 官方文档或响应结构变化时，增加合成兼容用例并更新协议来源记录。
- 完成团队 Developer ID 签名与 Apple 公证的独立配置和目标 Mac 验证。现有 CI 预览不提供这些凭据或信任身份。
- 增加第二名人工维护者后，提高必需 PR 批准数量。

## 另行立项的范围

首次上架、定时发布、新的生产自动化或调度、Apple Silicon Mac 之外的平台支持，需要另行明确需求和验收条件。浏览器登录与人工状态录入继续作为具体问题无法自动确认时的补充手段。
