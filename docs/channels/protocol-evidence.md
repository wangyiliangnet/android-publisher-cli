# 渠道接口与验证范围

本页面向维护渠道代码的开发者，说明每个商店的请求顺序、哪些结果已经测试，以及修改前还需要核对什么。操作者准备账号资料，请读[配置应用与渠道账号](../configuration.md)。

六个适配器只更新已有应用。发布策略 `after_approval` 表示审核通过后立即上架。运行 `android-release protocols` 可查看 CLI 记录的验证范围。

## 写入步骤与接口限制

“申请上传授权”是向商店取得本次上传地址及授权资料；“绑定”是把已上传文件关联到应用版本。“提审”是请求商店审核这次更新。

| 渠道 | 写入顺序 | 维护时须核对的条件 |
| --- | --- | --- |
| 华为 | 申请上传授权、上传、绑定、更新中文说明、提审 | 上传地址和签名头须匹配授权；绑定后至少等待 2 分钟再提审 |
| 荣耀 | 申请上传授权、上传、绑定、更新中文说明、提审 | 审核查询使用本次 `releaseId`；更新语言时使用 `setAll: 0` |
| 小米 | 签名后推送 APK 与图标 | 包查询不能确认本次审核结果；可选测试账号 JSON 从私有文件读取 |
| OPPO | 申请上传授权、上传、提审 | 上传授权本地使用期限为 30 秒；预检读取完整的已有应用资料 |
| vivo | 上传、提审 | 每次一个 APK；签名方法和账号权限仍需真实验证，请求至少间隔 1 分钟 |
| 应用宝 | 申请上传授权、上传、提审 | 使用主开发者账号；审核查询缺少本次版本标识 |

华为、荣耀在预检时从后台简体中文条目中取得语言字段及已有描述。向导不再询问该字段，旧配置中的 `language_id` 仍可读取并在重配时保留。

## 如何理解验证结果

六个适配器通过了模拟接口响应测试，覆盖只读预检、请求步骤、回执保存，以及执行、审核、上架状态的分别记录。`protocols` 中各字段含义如下：

| 字段 | 当前含义 |
| --- | --- |
| `protocol_mock_verified: true` | 模拟响应测试通过 |
| `account_verified: false` | 尚无逐渠道真实账号权限验证证据 |
| `live_verified: false` | 尚无逐渠道真实公开上架验证证据 |

模拟测试不证明商店授权或实际审核行为。状态查询还须确认结果属于本次版本，限制见[查询结果](../status-and-recovery.md#为什么有些状态一直无法确认)。

响应丢失后，现有查询通常缺少能对应原请求的标识或 APK 校验值，`reconcile` 因此保留阻塞。新增自动恢复逻辑前，须先记录官方字段如何证明原操作已执行或未执行，再补充相应测试。未知状态码、缺失字段和其他版本的信息都不能证明本次发布成功。

## 修改前核对官方资料

下表是研究接口的官方入口，可能要求登录或动态加载。字段的实际可用性仍需用获准的账号核对。

| 渠道 | 官方入口 | 核对内容 |
| --- | --- | --- |
| 华为 | [AppGallery Connect API](https://developer.huawei.com/consumer/en/doc/AppGallery-connect-Guides/agcapi-overview-0000001158245083) | 服务账号、上传授权、应用资料和提审字段 |
| 荣耀 | [API 包上传指南](https://developer.honor.com/cn/doc/guides/101359) | 访问令牌、应用编号、上传文件标识和发布结果 |
| 小米 | [自动发布 API 指南](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1134) | SIG 签名、包查询、推送和测试账号结构 |
| OPPO | [开发者服务中心](https://open.oppomobile.com/) | 访问令牌、上传地址、已有应用资料和提审结果 |
| vivo | [API 接入指南](https://developer.vivo.com/doc/detail?id=73) | 签名方法、账号平台和发布字段 |
| 应用宝 | [开发者 API 指南](https://wiki.open.qq.com/index.html#/guide/develop?id=4015262492) | 主开发者账号、文件序列号和审核查询 |

PR 需记录参考页面、字段、访问限制和仍待账号验证的行为。测试覆盖成功、错误以及发出请求后丢失响应的情况。协议代码独立实现，复用第三方代码前核对[来源与许可证](../../THIRD_PARTY_NOTICES.md)。
