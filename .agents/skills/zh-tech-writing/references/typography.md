# 排版细则

SKILL.md“排版”一节的补充。每条都带例子。

## 数字

**千分位**：五位及以上的数字加半角逗号；四位数可加可不加。

```
公司的实收资本为 ￥1,258,000。
```

**单位**：数字和英文单位之间加空格。

```
16 GB 内存
1 h = 60 min = 3,600 s
```

**货币**：数字前写货币符号，或数字后写中文名称。

```
$1,000
1,000 美元
```

**百分号**：半角 `%`，紧跟数字，不加空格：`6.5%`。

**范围**：用 `～` 或“至”连接，两端都带单位。

```
132 kg～234 kg
67%～89%
2009 年～2011 年
-20 °C 至 -10 °C
```

**增减**：“了”表示变化量，“到”表示结果。

```
增加到两倍：原来 1，现在 2
增加了两倍：原来 1，现在 3
降低到 80%：原来 100，现在 80
降低了 80%：原来 100，现在 20
```

减少只用百分比，不说“降低 N 倍”。

## 标点

**句号**：句末括号注释放在句号前面。

```
差：请参照第 1.3 节（见第 26 页。）
好：请参照第 1.3 节（见第 26 页）。
```

**括号**：补充说明用全角 `（）`，前后不加空格。

```
请确认所有连接（电缆和接插件）均已安装牢固。
```

**冒号**：解释说明用全角 `：`；时间用半角 `:`，如 `8:00`。

**逗号**：一段话里不能一逗到底。一个意思说完就用句号。

**分号**：只用在并列的分句之间。

**感叹号**：不用。不能连用 `！！`。

**破折号**：写成 `——`（占两个汉字宽）。尽量改用逗号、冒号或括号。

**连接号**：
- 两个名词复合、图表编号，用半角 `-`：`氧化-还原反应`、`图 1-1`。
- 数值范围用 `～`，见上文“范围”。

**行首**：句号、逗号、顿号、分号、冒号、问号、感叹号不出现在行首。

## 英文

**缩写**：第一次出现时，在括号里给出全称和中文，之后直接用缩写。

```
IOC（International Olympic Committee，国际奥林匹克委员会）
```

**大小写**：专有名词每个词首字母大写，普通名词小写。产品和技术名称按官方写法：`GitHub`、`JavaScript`、`macOS`。

**复数**：英文复数译成中文时还原成单数：`RAMs` → `RAM`。

**书名、文章名**：英文里的引号，在中文里改成书名号：`《航空业的未来》`。
